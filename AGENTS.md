# TravelAgency working agreements

- Work on a separate phase branch; never implement a phase directly on `main`.
- Preserve existing work and follow the supplied phase requirements and stop condition.
- Run the required verification and update the phase documentation.
- The user has given standing authorization to stage and commit completed phase work. Always create a commit when a phase is finished.
- Push, create pull requests, and merge only when the user requests those actions.
- Never discard changes, force-push, or delete unmerged branches.
